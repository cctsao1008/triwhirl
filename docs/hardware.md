# Hardware map

Status vocabulary:

- **schematic-derived**: directly traceable to TRC-V1.0 schematic/netlist.
- **physically verified**: confirmed on the actual board.
- **unknown**: not yet established.

## Motor and encoder path

| Signal | ESP32 GPIO | Status |
|---|---:|---|
| `Moto_IN1` | 25 | schematic-derived |
| `Moto_IN2` | 33 | schematic-derived |
| `Moto_IN3` | 32 | schematic-derived |
| `5600_SCL` | 5 | schematic-derived |
| `5600_SDA` | 23 | schematic-derived |

The schematic uses an EG2133 three-phase gate driver. Each `Moto_INx` net is routed to one high-side input and its corresponding active-low low-side input, so firmware drives the bridge as a 3-PWM interface.

The motor bridge is powered from a nominal 12 V rail generated by the onboard boost converter. Actual bus voltage under load has not yet been measured.

## Items intentionally not assumed

The following must be established by measurement or physical inspection before closed-loop FOC:

- motor pole-pair count
- motor phase order relative to `Moto_IN1/2/3`
- AS5600 positive mechanical direction
- electrical zero / sensor alignment
- safe continuous and transient `Vq`
- actual bus-voltage behavior under load
